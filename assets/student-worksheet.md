# 學生工作單：AI遊戲設計競賽

## A. 問題界定

1. 玩家是誰？在什麼情境遊玩？
2. 玩家最重要的行動是什麼？
3. 哪些條件不可違反？
4. 什麼證據可以顯示遊戲好玩、有效且可製作？

## A2. 教育獎勵函數

1. 在L學習、E投入、M動機／自我效能、A適切挑戰中，最重要的兩項是什麼？為什麼？
2. 將100%分配給L/E/M/A：L___%／E___%／M___%／A___%。
3. G猜答／鑽漏洞與C認知負荷的最大懲罰各為___分、___分。
4. 哪些資料可以計算六個構面？哪些目前只是推測？

## B. 三個候選概念

對每個概念填寫：玩家角色、核心動詞、30秒循環、壓力來源、主要取捨、成功／失敗、最大假設。

## C. 先行評分

在看到AI結果前，為每個概念評G、R／Purpose、D與L/E/M/A/G/C，計算R_edu，並寫下一項可觀察的證據。

## D. 比較AI排名

1. 哪一項分數差異最大？
2. AI使用了證據，還是推測？
3. 哪個淘汰理由最有說服力？
4. 哪個高分可能是reward hacking？

## E. 人類決策

選擇、修改或拒絕AI推薦。提出一個低成本原型，以及能推翻自己設計假設的測試結果。
